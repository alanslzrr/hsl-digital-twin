# Estilo de los diagramas

Fondo blanco, acento azul `#315f9b`, texto `#243347` y flechas grises. Formato horizontal 1280 × 720. Se utilizan Arial y Georgia, sin descargar fuentes. El HTML es editable y autosuficiente; el SVG se exporta para insertarlo como vector en el PDF. Arquitectura, flujo de decisión y secuencia siguen las convenciones de diagram-design.
